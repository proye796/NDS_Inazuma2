## 추가 기능

통신이나 지금은 끝난 배포가 있어야 얻을 수 있던 요소를 혼자서 얻을 수 있게 했습니다. 자동으로 주는 것은 없고, 구매·영입·승리 조건은 원작 그대로입니다.

| 기능 | 원작 | 이 패치 |
|---|---|---|
| 배포 데이터 받기 | 2009~2010년의 Wi-Fi·무선 배포로 받던 선수와 상품 | 타이틀의 통신 → 다운로드에서 Wi-Fi나 무선을 고르면 실제 통신 없이 배포 전체를 받습니다. 선수 60명(Wi-Fi 52명·무선 8명)과 상품 12종(Wi-Fi 8종·무선 4종)의 잠금이 풀리고 블로그 안내도 등록됩니다. 선수는 「이름으로 찾기」로 스카우트하고 상품은 역 앞 매점에서 삽니다. 자동 지급은 아닙니다. |
| 카오스 해금 | 자기 버전 라이벌을 이긴 뒤 다른 버전과 시크릿 통신 | 자기 버전 라이벌을 이긴 뒤 통신 → 시크릿에서 혼자 해금합니다. 이어지는 제국학원의 카오스 이벤트는 원작 그대로입니다. 라이벌을 이기는 순간 자동으로 풀리지는 않습니다. |
| 협력 경기 16개 | 프리미엄 대전 루트 2·4의 협력 조건 경기를 두 사람이 통신으로 진행 | 내 팀(선발 11명·벤치 5명)으로 혼자 진행합니다. 상대·선행 경기·승리·S등급·보상 조건은 그대로입니다. 일반 경기 방식으로 치르므로 난이도와 경험치가 원래 협력 경기와 같다고 보장하지는 않습니다. |
| 스카우트 암호 안내 | 특수 암호 8개의 안내를 게임 안 문구에서 찾을 수 없음 | 히비키 감독의 스카우트 메뉴에 「암호 안내」를 넣었습니다. 4명씩 두 쪽이며 좌우·A·행 터치로 쪽을 넘기고 B로 돌아옵니다. 암호는 「이름으로 찾기」에 붙여 입력합니다. 영입 조건은 원작 그대로입니다. |
